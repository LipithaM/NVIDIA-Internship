# Day 1 — Internship Orientation & GPU Lab Setup

## Overview

Day 1 marked the start of the NVIDIA Summer Internship Program. The session focused on onboarding, orientation, and gaining hands-on access to the GPU lab environment. Interns were introduced to the Kubernetes cluster and learned how to deploy and manage containerized workloads using Pods and Services.

## Objectives

- Complete orientation and onboarding procedures
- Get familiar with the GPU lab infrastructure
- Access the Kubernetes cluster and verify connectivity
- Create and manage Kubernetes Pods
- Expose applications using Kubernetes Services
- Understand the basic deployment workflow

## Topics Covered

- Internship program structure and expectations
- GPU lab environment overview
- Kubernetes fundamentals (Pods, Services, Deployments)
- Container orchestration concepts
- Cluster access and authentication
- Basic networking in Kubernetes

## Hands-on Activities

1. **Orientation & Onboarding** — Attended the program kickoff, reviewed safety and lab policies, and set up access credentials.
2. **GPU Lab Introduction** — Explored the lab environment and identified available GPU resources.
3. **Kubernetes Login** — Authenticated to the cluster and verified namespace access.
4. **Creating Pods** — Deployed a simple Pod using `kubectl` and verified its running status.
5. **Creating Services** — Exposed a Pod using a Kubernetes Service and tested connectivity.
6. **Deployment Workflow** — Walked through the lifecycle of deploying an application on the cluster.

## Key Learnings

- Understood the internship roadmap and expectations
- Gained practical experience with `kubectl` commands
- Learned how to create and manage Kubernetes Pods and Services
- Understood the role of container orchestration in GPU-accelerated workloads
- Built a foundation for deploying machine learning pipelines on Kubernetes

## Technologies Used

- **Kubernetes** — Container orchestration platform
- **kubectl** — CLI tool for managing Kubernetes clusters
- **NVIDIA GPU Lab** — High-performance computing environment with H200 GPUs
- **Docker** — Container runtime (underlying Pod deployments)

## Summary

Day 1 established the groundwork for the internship. By the end of the session, interns were comfortable navigating the GPU lab environment, interacting with the Kubernetes cluster, and deploying basic Pods and Services. These skills will be essential for scaling and managing GPU-accelerated ML workloads in the coming weeks.
