# Day 2 — Machine Learning Fundamentals

## Overview

Day 2 introduced core machine learning concepts with a focus on supervised learning techniques. The session covered regression and classification algorithms, the problem of overfitting, and best practices for building robust models using Scikit-learn. GPU-accelerated ML concepts were also discussed to set the stage for high-performance training workflows.

## Learning Objectives

- Understand the fundamentals of supervised machine learning
- Implement regression models for continuous target prediction
- Build classification models for categorical outcomes
- Identify and mitigate overfitting using regularization and validation
- Use Scikit-learn to train and evaluate ML models
- Explore how GPUs can accelerate machine learning workloads

## Concepts Covered

- **Supervised Learning** — Training models on labeled data
- **Regression** — Predicting continuous values (e.g., linear regression, polynomial regression)
- **Classification** — Predicting discrete class labels (e.g., logistic regression, decision boundaries)
- **Overfitting & Underfitting** — Bias-variance tradeoff and generalization
- **Train/Test Split** — Evaluating model performance on unseen data
- **Regularization** — Techniques (L1/L2) to prevent overfitting
- **Cross-Validation** — Robust model evaluation using k-fold CV
- **GPU Acceleration** — Leveraging GPUs for parallel computation in ML

## Practical Implementation

- Loaded and explored datasets using Pandas
- Visualized data distributions and correlations with Matplotlib/Seaborn
- Split data into training and testing sets
- Trained linear and logistic regression models using Scikit-learn
- Evaluated model performance using metrics like accuracy, precision, recall, and RMSE
- Applied regularization techniques to reduce overfitting
- Discussed the role of GPU acceleration in scaling ML training
